# Auftrag A-201a · Kanon-Parser und Overlay in Dart
1. **Rolle:** Baumeister
2. **Aufgabe:** Portiere das Einlesen des Kanons aus `krimidinner/spuk-im-gewoelbe/90_werkzeug/kanon.py` nach Dart (Paket `packages/burgstadt_core`) und ergänze das Zusammenführen mit dem Overlay `nachtlauf/kanon/ANPASSUNG.md`.
3. **Spiel:** „Burgstadt Schartenfels“ ist ein Ich-Perspektive-Krimi mit 2,5D-Pixelfiguren in einer verschlossenen, nächtlichen Burgstadt im Stil siebenbürgischer Burgstädte. Eine Freundesclique feiert Geburtstag im Gewölbe der Stadtburg; um 23:58 fällt in der ganzen Oberstadt der Strom aus, der Burgwart wird in der Speisekammer niedergeschlagen (er überlebt) und sein Schlüsselbund mit den Stadttor-Schlüsseln ist weg. Das Geburtstagskind ermittelt als Detektiv, 4 bis 20 Mitspieler (oder Bots) spielen die Rollen der Clique mit eigenen Geheimnissen, Gesprächen und Entscheidungen. Jede Rolle sieht und findet anderes, Hinweise lassen sich gezielt teilen oder an die Fallakte heften. Drei Nachtphasen, die der Uhrturm anschlägt, enden im Morgengrauen mit Eingrenzung, Anklage und einem von vier Enden.
4. **Kanon-Auszug:** Format `krimidinner/spuk-im-gewoelbe/10_kanon/FORMAT.md`. Nur Dateien `10_kanon/K*.md` (nicht `entwuerfe/`). Zeilen-Regex wie kanon.py: `^@(?P<id>[A-Za-zÄÖÜäöü0-9\-_.]+)\s*\[(?P<s>[OGL])\]\s*(?P<rest>.*)$`; Felder an ` | ` trennen, jedes Feld am ERSTEN `": "` in Name und Wert, beides getrimmt; ein Wert `–` bedeutet leer. Overlay-Regeln stehen oben in `nachtlauf/kanon/ANPASSUNG.md`: gleiche ID → genannte Felder ersetzen, `Löschen: Feld1, Feld2` entfernt Felder; neue ID → neuer Datensatz; `@ERSETZE-nn | Von: … | Nach: …` → exakte Begriffsersetzung (groß/klein-genau) in allen Feldwerten aller Datensätze NACH dem Mergen, in der Reihenfolge der Nummern; ERSETZE-Datensätze selbst landen nicht im wirksamen Kanon.
5. **Stil:** reines Dart 3, keine Pakete außer `test`/`lints`, deutsche Bezeichner wie im Bestand (z. B. `KanonDatensatz`, `Sicht`), Kommentare knapp auf Deutsch.
6. **Schnittstellen:**
   - `lib/src/kanon/kanon.dart`: `enum Sicht { o, g, l }`; `class KanonDatensatz { String id; Sicht sicht; Map<String,String> felder (Reihenfolge erhalten); String datei; int zeile; String? feld(String name) }`; `class Kanon { Map<String,KanonDatensatz> datensaetze; static Kanon lesen(String kanonOrdner); static Kanon ausText(Map<String,String> dateiInhalte); Kanon mitOverlay(String overlayText, {String datei}); Iterable<KanonDatensatz> mitPraefix(String p); }`. Doppelte IDs → `FormatException` mit Datei und Zeile.
   - `lib/src/kanon/proben.dart`: Portiere ALLE Proben aus kanon.py 1:1 (probe_syntax, probe_ersatz, probe_last, probe_absicherung samt `verfuegbar`/`tatsaechliche`/`gespraeche`, probe_zeit, probe_d, probe_e, probe_vollst) als Funktionen `List<String> probeXyz(Kanon k)` plus `Map<String,List<String>> alleProben(Kanon k)`. Gleiche Logik, gleiche Befundtexte wie Python. Für den Original-Kanon müssen sie wie `python3 krimidinner/spuk-im-gewoelbe/90_werkzeug/kanon.py pruefe` 0 Befunde bei 1207 Datensätzen melden. Prüfe die Gleichwertigkeit zusätzlich mit absichtlich kaputten Testtexten (z. B. Gespräch mit falschem Min, fehlender HW-Datensatz), bei denen Python und Dart dieselben Befunde liefern (Python dafür mit einem temporären Ordner unter /tmp aufrufen).
   - `lib/src/kanon/overlay_diff.dart`: `List<String> overlayDiff(Kanon alt, Kanon neu)` – je geändertem Datensatz eine Zeile `ID · Feld: alt → neu`, neue Datensätze `+ ID`.
   - `bin/kanon.dart`: `--pruefe` (Original + Overlay lesen, Zahlen und Befunde ausgeben, Exit-Code 1 bei Befunden), `--wirksam` (wirksamen Kanon im @-Format auf stdout), `--diff` (Overlay-Diff). Pfade relativ zum Repo-Wurzelordner (finde ihn, indem du von `Directory.current` aufwärts nach `krimidinner/` suchst).
